# 火柴人格斗游戏开发计划

## 📋 项目概述

本项目是一个基于 React + TypeScript + Vite 的火柴人格斗游戏，支持三种游戏模式：
- 人机格斗（玩家 vs AI）
- 双人格斗（玩家1 vs 玩家2）
- 机器格斗（AI vs AI）

## 🛠️ 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 框架 | React | 18.x |
| 语言 | TypeScript | 5.x |
| 构建工具 | Vite | 6.x |
| 样式 | TailwindCSS | 3.x |
| 游戏渲染 | Canvas API | - |
